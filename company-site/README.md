# GS Company Website

This folder contains the multi-page GS Company website recovered from its Vercel deployment.

- `index.html` — GS Company homepage
- `gs-events.html` — GS Events
- `gs-lux.html` — GS Luxe
- `gs-fast-juice.html` — GS Fast Juice landing/store page
- `css/`, `js/`, `data/`, and `assets/` — shared styles, scripts, product data, and brand asset

The existing standalone GS Fast Juice project remains at the repository root. This folder preserves the separate company website without overwriting it.
